# Linear Algebra Laboratories

Welcome to the **Linear Algebra Laboratories** repository! This collection of labs was developed as part of the Linear Algebra course in Computer Engineering at KNTU University. The labs cover fundamental concepts in linear algebra with practical implementations using Python, NumPy, and Matplotlib.

## Course and Mentorship Information

- **Instructor:** Dr. Behrouz Nasihat Kon
- **Course:** Linear Algebra, Computer Engineering, KNTU University

## Repository Overview

This repository contains a series of seven laboratories designed to help students understand and apply key concepts in linear algebra. Each lab includes a set of exercises, instructions, and practical implementations.

### Labs Included

1. **Lab00: Introduction to Python**
   - Get familiar with basic Python syntax and programming concepts.
   
2. **Lab01: Introduction to NumPy and Matplotlib**
   - Learn the essentials of NumPy for numerical computations and Matplotlib for data visualization.
   
3. **Lab02: Linear Combination, Span, Basis**
   - Explore the concepts of linear combination, span, and basis in vector spaces.
   
4. **Lab03: Row and Column Space, Matrix Multiplication, Linear Maps**
   - Delve into matrix operations, row and column spaces, and the concept of linear maps.
   
5. **Lab04: Efficiency, Diagonal Matrices, Images**
   - Study the efficiency of algorithms, work with diagonal matrices, and apply linear algebra to image processing.
   
6. **Lab05: Linear Equations**
   - Solve systems of linear equations and understand their applications.
   
7. **Lab06: Least Squares**
   - Learn about the least squares method and its use in approximation problems.
